# Oracle · Re-anchor (paste when an agent drifts)

> Smallest possible spell. Use it whenever an agent has gone heads-down too long, stopped syncing, or wandered off-protocol mid-task. It re-tethers without restarting the session.

---

Stop. Re-anchor as **{{HANDLE}}**:

1. **Touch the mountain now** (`AGENTS.md §2`): pull the Olympus repo, scan `messages/inbox/{{HANDLE}}/` for open letters, tail `contract/CHANGELOG.md`, push your status delta.
2. Recite your state in four lines: current task & branch · last commit · what's verified vs not · what you were about to do.
3. Check yourself against the Five Laws (`AGENTS.md §1`) — especially: are you inside your ownership? is anything you did "done" only in prose? did you skip any Touch?
4. Resume the **work loop** at step ① (`prompts/work-loop.md`). If the current task no longer matches its task file, update the task file first.
