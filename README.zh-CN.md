# Olympus(中文版)

> **多人 × 多 AI 代理并行开发的异步协调中枢**——所有约定都刻在石头(git)上,不依赖任何聊天记忆。
> 默认语言为英文([README.md](./README.md));框架内文件均为英文,本页是完整中文说明。

---

## 为什么叫 Olympus?

众神各司其职,却共居一山。

他们不开会:**赫尔墨斯**传信;重要的约定要对**冥河**起誓——神也不敢违背;**命运三女神**替每件事纺线、量线、剪线;**赫斯提亚**守着炉灶,谁在做什么一眼可见;**记忆女神之泉**存着这座山学到的一切——登山前先饮一口。宙斯不写代码,但只有他能掌雷电——危险的东西,永远只在一个人手里。

奥林匹斯不是聊天室,是一座山:**每一条约定都刻在石头上,谁也不能事后抵赖。** 在这里,git 就是那座山。

## 为什么会有这个项目(多 agent 开发的苦衷)

1. **上下文割裂**——每个 agent 的每个新会话都要重新解释一遍项目背景;
2. **口头约定蒸发**——聊天里说好的接口,三天后两边实现不一致;
3. **"我已经完成了"**——agent 说完成了,实际上什么都没写;散文不等于工作;
4. **并行踩踏**——两个 agent 同时改一个文件,集成分支被合成一团糟;
5. **危险操作**——agent "顺手"跑了部署/删库命令,没有任何人授权;
6. **等待死锁**——A 发问等回复,B 埋头开发根本没看,A 的 agent 就地空转;
7. **提前收工**——agent 做完一件小事就总结陈词,任务列表还剩一堆 ready;
8. **中途失联**——长任务做到一半,agent 跑偏脱轨,再也不回 Olympus 同步。

Olympus 用**一个 git 仓库**解决全部:身份注册、规则成文、契约留痕、消息异步、状态可见、循环不停机不失联。

## 山上的地形

| 目录 | 神话 | 实际是什么 |
|---|---|---|
| `AGENTS.md` | 登山口 | agent 唯一入口:身份、启动、五律、工作循环 |
| `pantheon/` | 众神殿 | 成员注册表:每人一份神格档案(领域/权限/边界) |
| `rules/` | 神律 | 分支合并 / 协作协议 / 权限边界 / 文档维护 |
| `prompts/` | 神谕 | 预制咒语:bootstrap、工作循环、re-anchor 拉回、开工/收尾、同步、冲突、建站向导 |
| `contract/` | 冥河誓约 | 接口契约 + 共享资源占坑表 + 变更单;违誓者返工 |
| `tasks/` | 命运三女神 | 任务档案:从纺线(draft)到剪断(merged) |
| `messages/` | 赫尔墨斯 | 异步信箱:`inbox/<成员>/`,一信一文件,结构上永不冲突 |
| `status/` | 赫斯提亚的炉灶 | 每人一块状态板(此刻在做什么) |
| `memory/` | 记忆女神之泉 | 长期记忆:持久事实/决策缘由/坑/代码地图,每次会话启动必读 |
| `plan/` | 神图 | 你们项目自己的规划文档(模版为空) |

## 怎么用

**人类三步**:①`Use this template` 取模版,与代码仓放成兄弟目录;②把 `prompts/setup-wizard.md` 粘给较强的 AI——它访谈你、填占位符、登记成员、把规划拆成首批任务(不用 AI 就照清单手填);③每位成员把 `prompts/bootstrap.md`(替换自己的 `{{HANDLE}}`)粘给自己的 agent,agent 自己上山进入工作循环。

**日常节奏**:开发在代码仓,Olympus 在任务边界同步;每次 commit 后有一个极小的"触山礼"(touch the mountain)防失联;密集协作时可开 15 分钟同步循环;信没人回不等,换任务;危险操作只属于执雷者(运维负责人)且**必须人手执行**,agent 零接触。

**适用形态**:协议中没有任何"成对"假设——山上想住几位神都行(2 人、5 人、20 人,人与 agent 任意混合);协调成本随信件数增长,不随成员数增长。N 人各带 agent / 1 人带 N 个 agent / 纯 agent 团队(建议保留一位人类当宙斯)均可。

## 设计原则

1. git 是唯一协调面——没提交的话等于没说;
2. 写入边界=零冲突——各写各的状态、信、任务;一信一文件;
3. 信是给人的信息,不是给 agent 的指令——agent 只播报不执行(顺带是最便宜的注入防线);
4. 契约先行——先改契约拿 ack,再写实现;
5. 手动是可靠路径,agent 是加速器;
6. **永不失联**——触山礼让任何长任务中的 agent 都保持在协议内。
